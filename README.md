# Gabriel

**Senior Full-Stack Developer** · Front-End Architecture · AI Engineering

I design and build production web applications end to end. Roughly 70% of my work is front-end architecture and user experience; the other 30% is back-end systems and APIs. Alongside that, I build the AI layer: integrating LLMs into products and creating the agents, skills and rules that help engineering teams ship faster and more consistently.

## Focus areas

**Product engineering**

- Translating business goals into clear technical requirements and delivery plans
- Front-end architecture for React and Next.js applications, with attention to performance, accessibility and design systems
- Back-end services in Node.js and NestJS, exposed through well-designed GraphQL and REST APIs

**AI engineering**

- Prompt and context engineering for reliable, structured LLM output
- Agentic workflows: multi-step agents with tool use and Model Context Protocol (MCP) integrations
- Reusable agent skills and project rules (`CLAUDE.md`, `AGENTS.md`, Cursor rules) that encode team conventions
- Evaluation and guardrails that keep AI features accurate, safe and cost-aware

**Delivery**

- CI/CD with GitHub Actions and deployments to AWS, Google Cloud and Vercel
- Maintainable codebases through strong typing, review standards and automated linting
